# 可信查询Skill

## 1. 作用

把`QueryTask`转换为安全的只读查询。重点解决指标口径不明确、大Schema选错字段、错误表关联和查询结果过大。

## 2. 实现流程

```text
输入：QueryTask + Runtime Context
指标、维度、筛选、确定时间、权限
  ↓
[规则] 权限过滤并加载审核指标定义
  ↓
[Agentic RAG]
表召回 → 候选表内字段召回 → 审核关系补全表关联
  ├─ 信息不足：生成SchemaGap并全局补检，最多2轮
  ├─ 存在歧义：HITL
  └─ 信息完整
       ↓
[LLM] 生成结构化查询骨架，只引用metric_id
  ↓
[规则] MetricCompiler写入指标公式，生成SELECT
  ↓
[公共规则] SQL安全网关
  ├─ 拒绝：越权、错误关联、重复统计或高成本查询
  ├─ 可修复：有限次数重生成
  └─ 通过
       ↓
[公共Tool] 只读MySQL执行并流式写入Parquet
  ↓
输出：result_id + 有界摘要 + 指标/Schema版本
```

## 3. Schema Agentic RAG

知识库按三种对象构建：

| 对象 | 最小单元 | 主要内容 |
| --- | --- | --- |
| 表文档 | 一张表 | 完整表名、别名、用途、业务域、一行代表什么 |
| 字段文档 | 一个字段 | 完整字段名、别名、含义、类型、单位、所属表 |
| 关系图 | 一条表关系 | 两端表、关联字段、一对一/一对多、来源和版本 |

BM25处理表名、字段名和缩写，向量检索处理业务描述。关系图只保存数据库外键或人工审核过的业务关系，不能由Embedding或LLM猜测。

```text
表召回 → 表内字段召回 → 关系图补全
                         ├─ 完整：生成查询
                         ├─ 歧义：HITL
                         └─ 缺失：SchemaGap → 全局字段补检 → 再次补全
```

`SchemaGap`说明缺少什么概念、用途和约束。补检通过全局字段检索找到字段及所属表，再更新候选表。连续两轮没有新增对象时停止。

权限过滤在召回前完成。Schema Catalog通过离线任务同步DDL、注释和审核关系；版本变化后，旧任务必须重新召回。

## 4. 指标与SQL安全

指标语义层保存公式、固定筛选、时间字段、单位和版本。LLM只选择`metric_id`，`MetricCompiler`负责把审核定义写入SQL。

SQL安全网关以规则为主：

- SQLGlot按MySQL方言解析，只接受单条`SELECT`；
- 表、字段和权限必须与`QueryTask`一致；
- JOIN必须来自本次召回的审核关系；
- 根据一对多关系和指标所在数据层级，拦截重复统计；
- 拒绝`SELECT *`、无约束明细、锁定读、文件操作和危险函数；
- `EXPLAIN`检查扫描量，执行端限制时间、行数和文件大小。

LLM可以修复查询骨架，但不能决定SQL是否安全。缺少表关系或指标定义时进入HITL或拒绝执行。

Schema召回前、HITL恢复后和SQL执行前都重新加载权限，避免暂停期间权限已经变化。

## 5. 结果与多轮查询

执行前创建`result_id`和`WRITING`记录，结果流式写入`.part`文件；完成后原子重命名为Parquet并标记`READY`。失败或超限时删除临时文件。

`result_summary`只包含回答需要的有限数值、单位、时间范围和数据截止时间。完整结果通过`result_id`访问，不进入LLM上下文。

后续问题分两类：

- 已有列上的筛选、排序、选列或TopN：规则生成参数化DuckDB查询，读取Parquet并生成新`result_id`；
- 新增指标、维度、时间或缺失字段：合并上一轮`QueryTask`，重新查询MySQL。

Result元数据记录来源表、字段和权限版本。每次读取都校验租户、所有者、实时权限、TTL和`READY`状态；权限发生变化时拒绝旧结果并重新查询。前端分页只读取Parquet，不能绕过结果大小限制。

## 6. 输入输出与边界

| 类型 | 内容 |
| --- | --- |
| 输入 | `task_id`、指标、维度、筛选、时间范围、权限 |
| 输出 | `result_id`、摘要、列与行数、数据截止时间、指标/Schema版本、错误状态 |

支持MySQL可表达的聚合、JOIN、同比、环比、占比和TopN。不支持预测、聚类、跨数据源计算、LLM生成的Python/Pandas代码、无约束`SELECT *`和任意临时结果SQL。
