# 数据库设计

> 返回 [需求文档索引](./需求文档.md)

使用 SQLite 构造电商经营分析数据集。

包含：

- **8 张业务表**：供 Agent NL2SQL 分析（及 admin 受控写）
- **1 张应用账号表 `app_users`**：注册登录用，与业务 `users` 隔离，默认不进入 Schema Linking / NL2SQL

## 0. app_users（应用账号，非业务表）

字段：

- id
- username
- password_hash
- role（`analyst` | `admin`）
- created_at

说明：

- 仅由 `/api/auth/*` 读写
- Guardrail 禁止业务 SQL 访问或修改本表
- `admin` 注册需校验环境变量邀请码，邀请码不入库

## 1. users

用户表（电商业务用户，不是登录账号）。

字段：

- id
- name
- city
- province
- gender
- age_group
- register_date
- channel

## 2. products

商品表。

字段：

- id
- name
- category
- brand
- price
- cost
- status

## 3. orders

订单表。

字段：

- id
- user_id
- order_date
- status
- total_amount
- pay_amount
- channel
- province
- city

## 4. order_items

订单明细表。

字段：

- id
- order_id
- product_id
- quantity
- unit_price
- discount_amount

## 5. payments

支付表。

字段：

- id
- order_id
- payment_method
- paid_at
- amount
- status

## 6. refunds

退款表。

字段：

- id
- order_id
- refund_date
- refund_amount
- reason
- status

## 7. campaigns

活动表。

字段：

- id
- name
- channel
- start_date
- end_date
- budget

## 8. traffic_logs

访问日志表。

字段：

- id
- user_id
- visit_date
- channel
- page_type
- session_id
- is_conversion

## 9. 数据要求

- 业务表生成不少于 1000 条模拟数据
- 时间跨度覆盖最近 180 天
- 包含多个渠道、城市、品类、支付方式、退款原因
- 数据能支持 GMV、订单量、退款率、转化率、客单价、利润率等分析
- 可预置 1 个演示用 `analyst` 账号；`admin` 通过邀请码注册或文档说明创建方式
