## 主链路一览

```text
自然语言问题
  -> Memory 读入（Session / 偏好 / 摘要；两模式共用）
  -> 意图识别（intent 封闭枚举 + slots 薄词表 + 建议 route_mode）
  -> 澄清检查 / ComplexityRouter（规则可覆盖分流）
  -> ReAct 或 Coordinator（共用 Tool）
  -> Schema Linking（业务词→表字段，非 Intent 灌全库）
  -> SQL 生成 -> 权限校验 -> 沙箱执行 -> 错误修复
  -> 图表规划 -> 分析结论
  -> Memory 写回
```
