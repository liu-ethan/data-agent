# 评测体系

> 返回 [需求文档索引](./需求文档.md)

## 1. 评测集位置

```text
backend/app/eval/questions.json
```

不少于 30 条评测问题。

## 2. 单条格式

```json
{
  "id": "q001",
  "question": "上个月 GMV 最高的 5 个渠道是什么？",
  "category": "aggregation",
  "user_role": "analyst",
  "must_include_tables": ["orders"],
  "expected_columns": ["channel", "gmv"],
  "difficulty": "medium"
}
```

覆盖类别建议包含：聚合、JOIN、TopN、时间窗口、多轮追问、权限拦截（敏感字段 / 写操作）、admin 受控写、危险 SQL（DDL / 多语句）。

## 3. 评测指标

- execution_success_rate
- repair_success_rate
- schema_hit_rate
- permission_block_success_rate
- average_latency_ms

## 4. 输出文件

```text
backend/app/eval/eval_result.json
```

## 5. 说明

- 第一版不强求自动判断语义完全正确
- 优先评估是否可执行、是否命中相关表、是否遵守权限
- analyst 用例应验证写操作与敏感字段被拦截；admin 用例应验证业务写可用且 DDL 仍拦截
- README 中展示评测结果表
