data-analysis-agent [GitHub链接]：面向电商经营分析场景，构建自然语言问数、SQL 生成、安全执行、图表规划和结论输出的智能分析助手

- Agent 编排与路由：基于 LangGraph 将分析链路拆为意图识别、任务分流、表结构检索、SQL 生成、安全校验、查询执行、图表规划等 16 个节点；简单查询走 ReAct，复杂分析走 Coordinator，并用规则覆盖模型分流结果。
- Text-to-SQL：将 GMV、订单数、客单价等 8 类指标口径沉淀为 YAML 知识库；SQL 生成阶段只注入相关表字段、指标口径和权限约束。
- 上下文治理：意图阶段仅抽取业务对象、时间范围与指标候选，不暴露完整数据库表结构；相关表结构命中率约 85%，单次 Prompt Token 降低约 40%。
- SQL 安全治理：封装表结构、指标口径、SQL 校验、执行、图表生成等 6 类工具；SQL 执行统一经 Guardrail 校验，执行失败后结合报错与表结构优化 SQL，并重新校验后最多重试 1 次。
- 质量保障：围绕澄清、分流、权限、执行、修复、记忆与图表规划补充 190+ 条单元及链路测试，提升链路稳定性。
