data-analysis-agent：面向数据分析场景，构建从自然语言提问、意图识别、表结构匹配、SQL 生成与安全执行，到图表规划和中文结论输出的智能分析助手

Agent 工作流编排：基于 LangGraph 将一次数据分析拆分为记忆读取、意图识别、问题澄清、任务分流、表结构检索、SQL 生成、安全校验、查询执行、错误修复、图表规划和结论生成等步骤；简单问题走单 Agent ReAct 循环（Thought-Action-Observation），复杂问题走 Coordinator 多 Agent 编排（Supervisor-Worker：主 Agent 调度专责子 Agent），并用规则覆盖模型分流结果，避免单个大 Prompt 同时负责理解、生成和执行导致过程不可控

Text-to-SQL：将销售额、订单数、客单价等指标口径沉淀为 YAML 知识库，支持按名称查询与口径校验；意图识别只抽业务概念、不灌全库 Schema，明确指标走规则注入 SQL 生成，不明确则由 ReAct 按需查知识或澄清，降低 Prompt 膨胀与字段幻觉

工具调用与 SQL 安全治理：封装表结构查询、指标口径查询、SQL 校验、SQL 执行、图表生成等工具，统一维护工具参数、风险等级和调用权限，并记录每次工具调用的开始、结束、耗时和结果；SQL 执行前通过确定性规则拦截多语句、建删表等危险操作、系统表访问和普通用户敏感字段查询，管理员写操作限制影响行数并写入审计日志

错误修复与多轮记忆：SQL 执行失败后，将原始问题、失败 SQL、错误信息和相关表结构交给修复节点最多重写一次，修复后的 SQL 必须重新经过安全校验；实现会话内槽位合并和跨会话偏好记忆，支持“那按城市拆一下”这类追问继承上一轮指标和时间范围；围绕问题澄清、任务分流、权限拦截、安全执行、SQL 修复、记忆合并和图表规划补充 190+ 条单元及链路测试
