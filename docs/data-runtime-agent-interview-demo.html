From question to governed result

不是生成 SQL，而是完成任务。

这张演示页只回答一个问题：用户的一句话，如何在有限 Agent 循环中完成 Schema 绑定、安全执行、多轮恢复和结果交付，同时不让模型绕过权限与数据库边界。

Agent 负责开放决策；检索负责绑定证据；Gateway 负责不可绕过的确定性边界。

Architecture backbone

五个 Node，一条可信路径

Node 只表示需要参与循环、恢复或路由的阶段；时间解析、权限检查、混合检索等能力保留为 Node 内部 Service，不再重复包装成 Tool。

NODE 01

agent_node

解析 TaskFrame，并依据 Coverage、Observation 与 GoalChecklist 决定下一步。

→
NODE 02

retrieval_node

统一完成首次 Schema 召回和 SchemaGap 定向补检。

→
NODE 03

query_generation_node

生成 QuerySpec + CandidateSQL，或返回缺失证据。

→
NODE 04

execution_gateway_node

读取强制安全检查；写入 Preview、HITL、参数化事务和审计。

→
NODE 05

response_node

基于真实 result_id 分析结果，生成表格、图表和回答。

execution / retrieval observation → agent_node：复杂任务可以回环，简单任务一次通过。 Coverage 不足禁止 GENERATE · GoalChecklist 未完成禁止 END

            Memory is lifecycle, not chat history
            
三层状态，按需进入 Prompt

          

          
模型没有隐式记忆。每次重入 agent_node 都读取结构化 State；跨轮通过 thread_id 恢复；跨会话只召回用户确认过的稳定偏好。

        

        

          

            Working state
            
当前任务工作状态

            
生命周期：一次 Graph 运行。

            
  • TaskFrame、Coverage、SchemaGap
  • latest_observation、GoalChecklist
  • 循环与召回预算、next_action

          

          

            Short-term
            
线程短期记忆

            
生命周期：同一 thread_id。

            
  • 滚动摘要与最近 4–8 条消息
  • 未完成任务与 Interrupt
  • result / artifact 引用与版本

          

          

            Long-term
            
用户长期偏好

            
生命周期：跨会话、用户确认后写入。

            
  • 时区、默认店铺、图表偏好
  • 不同 Key 增量，同 Key 版本化覆盖
  • 按 user_id + task_type 精确召回

          

        

        

          完整 State / MySQL Store→PromptContextBuilder 按 Node 投影→最小、可验证的 LLM 上下文
        

        
边界：指标口径、Schema、字段含义、JOIN 与 Verified SQL 属于管理员审核的共享语义目录，不属于某个用户的长期记忆。

四个可写进简历的亮点

          
“给模型动态决策空间，但不给它绕过权限、安全和副作用边界的能力。”

        

        

          
01
有限 Runtime Loop
Coverage、Observation 与 GoalChecklist 驱动动作，循环预算和 Interrupt 防止失控。

          
02
动态 Schema Linking
权限前置分层检索、最小 GroundedContext、SchemaGap 定向补检与可信 JOIN。

          
03
可信执行网关
AST、权限、语义、EXPLAIN、结果契约，以及写入 Preview + HITL。

          
04
分层记忆与成本
AgentState、Checkpoint、Artifact 和长期偏好分层，Prompt 按需投影。
